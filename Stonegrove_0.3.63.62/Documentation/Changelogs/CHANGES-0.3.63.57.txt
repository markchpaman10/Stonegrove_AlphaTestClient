Stonegrove 0.3.63.57

Mountains: Level Editor > Terrain > Mountain - Autotile.
Paint connected cells; edges, corners, and the two-tile rock face update automatically.
Brush, square, and circle tools are supported. Right-click erases (Shift + right-click when another editor inspector is under the cursor). Undo is supported.
Mountains save with every map in current.lua and export in the shared .sgworld file. Older maps need no conversion. Mountain tops and rock faces block movement.
Use the editor to paint the grassy footprint; the rock face extends two tiles below it. Leave space below for paths and doors.

Includes the character-loading fix, town camera tour, and organized documentation from previous releases.
Native LOVE verification: mountain painting, erasing, undo, map reload, world export/import, collision checks and rendered preview. All Lua files compile.
