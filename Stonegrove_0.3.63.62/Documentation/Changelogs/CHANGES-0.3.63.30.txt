STONEGROVE 0.3.63.30 - Starter inventory, Religion and bonfire regressions

New characters start with an empty carried inventory and exactly one of each of eight copper items in the bank: Axe, Pickaxe, Knife, Dagger, Hammer, Tongs, Longsword and Shield. Removed the duplicate carried Axe/Pickaxe/Knife; existing character inventories are preserved. Starter bank contents and save/profile round trips are explicitly checked.
All supported log types now show Add to Bonfire in the context menu. Selecting it explains Firemaking 10 or nearby-bonfire requirements rather than hiding the option. Poplar Logs work for both creating and refueling fires, matching the existing log-use UI. Bonfires retain 2-second fuel actions, 20-second log burns, 5 Charred Wood per log and a 5-minute temporary +20% Health/Defence buff. Fixed the main update loop still calculating Health from proximity rather than buff lifetime.
Multiplayer material blessing and feather carving now use server transactions that commit inventory changes and Religion XP together. Protected Religion XP high-water totals are updated on success and restored on database-failure rollback. Normal blessing and altar 2x bonus/cap are unchanged; repeated blessing gives no extra XP and altar bonuses require proximity. Earned XP now remains visible in Skills after multiplayer exchange and in durable character saves. Added Religion Altar world-hover help describing blessing, XP cap, distance and preserved material grades.
Regression investigation: duplicated carried starter tools and the main-loop radius check are present in the preserved 0.3.63.18 source. The 0.3.63.24 gravestone release added protected server Religion totals, while client-only blessing/carving still remained, allowing the next exchange to erase those local awards. The rune-grade release did not introduce those paths. The altar had no station help entry. All preceding content, graded spell materials and cave-restart fixes remain included. Update server and clients together.
