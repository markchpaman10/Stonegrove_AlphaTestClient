STONEGROVE 0.3.63.35 — USER BUG LIST
Completed all twelve requested items.

1. Rune Bag quality now sets capacity per material: D 50, C 60, B 70, A 80. Its equipped quality also multiplies spell damage/healing by 100%, 105%, 110%, 115%, on top of rune-material grade. Ungraded bags preserve the old 50/100% behavior. Capacity normalization never deletes existing contents; over-capacity contents can be withdrawn but cannot receive more materials. Hover and container display show actual capacity and spell bonus.
2. Shop buttons: Sell Inventory sells all accepted carried goods; currency, equipped items, tents rejected by traders, loaded rune bags/quivers and pending lobster tails remain protected. Buy Max applies to selected stock, buying the maximum affordable quantity that fits, up to remaining stock. Right-click Buy All uses the same behavior. Graded non-stackable purchases create separate items; payment, stock and inventory commit together. Online bulk sales use the server's transaction/replay/rollback path.
3. Cave entrance hover uses the entrance's actual min/max enemy levels, with the same area-level fallback used to generate the cave. Removed fixed 20–30 text.
4. Rawhide String stacks to 15 in inventory; bank withdrawals preserve all remaining quantities and split output to that stack size.
5. Admin menu Players tab selects an online character for item grants, skill levels, healing or town teleport. Target character ID and slot are verified by the authenticated server. Grants preserve target bank contents. Changes persist, synchronize to the target's next poll and wait for revision acknowledgment; stale polls and in-flight older save responses cannot undo the update; fresh combat damage is preserved. Duplicate requests do not repeat grants. Failed database writes roll back the target actor. Offline development and self-target administration remain available.
6. Gem dust consumption limits: Ruby/Onyx 10, Sapphire 20, Emerald 30. All Dust consumes only the limit and preserves the remainder. Cast time and XP use consumed quantity. Existing effect formula/caps remain: base + 0.1 per dust, capped at 10/20/30 respectively; Ruby with ten dust therefore gives +6, not an unlimited dust purchase of the effect cap.
7. Whole Small Fish cooking gives 40 base XP, Large Fish 60, Eel 80. Existing race multipliers apply (Human Small/Large show 44/66). Skill level thresholds and the global XP curve remain unchanged.
8. Raw Crab Meat, cooked crab grades and burnt crab meat now have an inventory stack limit of 10. New yields and withdrawals respect the limit. Existing oversized carried Crab Meat/Rawhide String stacks are split on load; overflow goes to the bank with grades preserved instead of being deleted.
9. Offensive and healing spell range rises from 180 to 210 world pixels. Mage enemy selection also reaches 210; physical attack reach is unchanged.
10. Stove/campfire recipes group Fish & Seafood before Other Food, ordered by level/name inside each group. The menu title shows the current group. Client and server share identical recipe indices.
11. Camera follows the player normally. Hold middle mouse to enable mouse-directed camera look; release to recenter. Added help text.
12. Friendly player selection requires an equipped Spellbook containing Healing Spell Page. Removing it clears the target. Enemy targeting and admin player selection remain independent.

Regression checks and limitations are in VALIDATION-0.3.63.35.txt. Update matching server and clients together; extract into new folders and preserve existing account/character data.
