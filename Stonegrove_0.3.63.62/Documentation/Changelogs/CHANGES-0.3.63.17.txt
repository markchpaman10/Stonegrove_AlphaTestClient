STONEGROVE 0.3.63.17 - Level editor world import

Added a visible Import Ctrl+I button and Windows world-file picker to the level editor. Choose an exported .sgworld package or current.lua/map Lua file; dragging either file into the editor also imports it. Packages retain every map, world identity, starting map, item/NPC/monster/quest/event definitions and imported PNG assets. Import updates the editor without writing the shared project until Save. Save applies staged definitions/assets with backups and restores changed files if a write fails. Reload clears staged imports. Invalid packages, unsupported layouts and malformed map collections show an error. Lua data imports run without global libraries. Existing project metadata and procedural settings are retained when editing/saving. Previous releases and all earlier gameplay changes preserved. Developer/server and alpha release versions aligned; alpha remains editor-free.
