STONEGROVE 0.3.63.33 - Placeable editor Bag Keeper

Added Bag Keeper to Level Editor Town / NPC palette. Place it like other vendors; it displays the supplied bag icon and a label. Includes the bag atlas in editor assets. Saved authored objects instantiate a working Bag Keeper at their exact coordinates in offline and multiplayer worlds. Explicit placement replaces automatic trader companions in that map; maps without a placed Bag Keeper retain the previous automatic fallback. Click navigation approaches the keeper before interaction. NPC appearance inspector linking, event hiding and editor world preview support the Bag Keeper. Starter grant eligibility, bank/ground/grave ownership checks and transaction persistence are unchanged. Previous graded rune bank and bag shop price fixes remain included. Update server and clients together.
